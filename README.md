# ⏰ Relógio Digital  

Este é um projeto simples de um Relógio Digital feito com HTML, CSS e JavaScript. Ele exibe a hora atual atualizada em tempo real.  

## 🚀 Funcionalidades  
- Mostra as horas, minutos e segundos em tempo real.  
- Formatação com zeros à esquerda (ex: 08:09:05).  
- Design responsivo com gradiente de fundo.  

## 📚 Tecnologias Utilizadas  
- **HTML5** para a estrutura do projeto.  
- **CSS3** com flexbox para o layout e gradiente para o fundo.  
- **JavaScript** para a lógica de atualização do relógio.  

## 🎨 Design  
O relógio é exibido no centro da tela, com um fundo em gradiente diagonal. As divisões de horas, minutos e segundos possuem:  
- **Fonte elegante** utilizando Open Sans.  
- **Efeito de sombra** para um visual moderno.  
- **Dígitos grandes** para fácil leitura.
